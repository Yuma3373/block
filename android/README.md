# 쇼츠·릴스 차단 (Android 앱)

유튜브 앱의 **쇼츠**, 인스타그램 앱의 **릴스** 화면이 열리면 바로 빠져나오는 안드로이드 앱입니다.
시중의 쇼츠/릴스 차단 앱들과 같은 방식(접근성 서비스)으로 동작합니다.

## 기능

- **탭 숨기기**: 유튜브 아래 메뉴의 **쇼츠** 버튼, 인스타그램의 **릴스** 버튼을 아예 없앤 것처럼 보이게 합니다.
  - 안드로이드 14 이상: 앱 화면에서 나머지 버튼(홈·구독 등)을 잘라 와 **빈틈 없이 고르게 다시 배치한 메뉴바**를
    진짜 메뉴바 위에 띄웁니다. 버튼을 누르면 진짜 버튼이 눌리고, 선택 표시·알림 점도 따라 바뀝니다.
  - 안드로이드 11~13: 쇼츠/릴스 버튼 자리만 배경색으로 덮고 눌러도 반응하지 않게 합니다.
  - 키보드가 올라오거나 다른 앱으로 가면 바로 사라집니다.
- **화면 차단**: 추천·링크·DM 등 어떤 경로로든 쇼츠/릴스 화면이 열리면 바로 **뒤로 가기**(또는 **홈 화면**)를 누르고,
  화면 가운데에 "쇼츠는 차단되어 있어요" 카드를 잠깐 보여줍니다.
- **기록**: 오늘 / 최근 7일 / 전체 차단 횟수와 요일별 그래프.
- **잠깐 쉬어가기**: 5·15·30분 동안만 풀어 두고, 시간이 지나면 자동으로 다시 막습니다.
- **시작 가이드**: 접근성 권한, "액세스가 거부됨" 해결(앱 정보 바로 열기), 배터리 제한 해제를 단계별로 안내합니다.
- 앱별·기능별로 따로 켜고 끌 수 있고, 다크 모드를 지원합니다.

접근성 서비스는 YouTube·Instagram 앱 화면만 받습니다. 탭 색을 맞추려고 화면의 한 점 색만 읽으며,
화면 내용은 저장하거나 전송하지 않습니다(인터넷 권한 없음).

유튜브 홈 피드 중간에 섞여 나오는 쇼츠 묶음은 스크롤에 따라 계속 움직여서 가리지 않습니다.
대신 눌러서 열면 화면 차단으로 바로 닫힙니다.

## 설치

1. 휴대폰 브라우저로 GitHub 저장소의 **Releases**에 들어가 가장 최신 `쇼츠·릴스 차단 APK`의
   `shorts-reels-blocker.apk`를 내려받습니다.
2. 내려받은 `shorts-reels-blocker.apk`를 눌러 설치합니다 ("출처를 알 수 없는 앱" 허용 필요).
3. 앱을 열고 **접근성 설정 열기** → 설치된 앱 → **쇼츠·릴스 차단**을 켭니다.
   - 안드로이드 13 이상에서 "제한된 설정" 때문에 켜지지 않으면:
     설정 → 애플리케이션 → 쇼츠·릴스 차단 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 시도하세요.
4. 삼성·샤오미 등 일부 기기는 배터리 최적화로 서비스가 꺼질 수 있습니다.
   설정 → 애플리케이션 → 쇼츠·릴스 차단 → 배터리 → **제한 없음**으로 바꿔 주세요.

## 직접 빌드

Android Studio로 `android/` 폴더를 열거나, Android SDK가 있으면:

```
cd android
./gradlew assembleRelease
```

## 앱이 업데이트돼서 다시 안 막힐 때

유튜브·인스타그램이 화면 구조(뷰 ID)를 바꾸면 감지가 안 될 수 있습니다.
`app/src/main/java/com/shortsblocker/Target.kt`의 `playerViewIds`에 새 ID를 추가하면 됩니다.
(새 ID는 Android Studio의 Layout Inspector나 "Developer Assistant" 같은 앱으로 확인할 수 있습니다.)

## iPhone은?

iOS는 다른 앱의 화면을 읽거나 조작하는 것을 허용하지 않아서, 앱 안의 쇼츠/릴스만 골라 막는 앱은 만들 수 없습니다.
iPhone에서는 **스크린 타임**으로 유튜브·인스타 앱 자체를 제한하고, Safari + 이 저장소의 브라우저 확장(Safari용으로 변환 필요)을 쓰는 방법이 현실적입니다.
