# 개인정보처리방침 — 쇼츠·릴스 차단

시행일: 2026년 10월 25일

"쇼츠·릴스 차단"(이하 "앱")은 이용자의 개인정보를 수집하지 않습니다.

## 1. 앱이 접근하는 정보

앱은 안드로이드 **접근성 서비스(AccessibilityService)** 를 사용하며, 이용자가 동의하고 직접 켠 경우에만 동작합니다.
접근 범위는 **YouTube(com.google.android.youtube)** 와 **Instagram(com.instagram.android)** 앱으로 한정됩니다.

| 접근하는 정보 | 목적 |
|---|---|
| 화면 구성 정보(버튼의 이름·ID·위치) | 쇼츠·릴스 화면이 열렸는지 판단, 아래 메뉴바의 쇼츠·릴스 버튼 위치 찾기 |
| YouTube·Instagram 앱 창의 화면 이미지 | 쇼츠·릴스 버튼을 뺀 메뉴바를 다시 그리기, 메뉴바 배경색 맞추기 |

## 2. 처리 방식

- 모든 처리는 이용자의 기기 안에서만 이루어집니다.
- 화면 이미지와 화면 구성 정보는 메모리에서 즉시 사용되고 저장되지 않습니다.
- 앱에는 **인터넷 권한이 없어** 어떤 정보도 기기 밖으로 전송할 수 없습니다.
- 제3자에게 제공하거나 광고·분석 목적으로 사용하지 않습니다.

## 3. 기기에 저장되는 정보

앱 설정(기능 켜기/끄기, 일시정지 시간)과 날짜별 차단 횟수만 기기 안에 저장되며, 앱을 삭제하면 함께 지워집니다.

## 4. 이용자의 권리

언제든 [설정 → 접근성]에서 서비스를 끄거나 앱을 삭제해 모든 동작과 저장된 정보를 없앨 수 있습니다.
