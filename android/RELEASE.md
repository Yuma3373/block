# Play 스토어 출시 가이드

처음부터 끝까지 순서대로 따라 하면 됩니다. (★ = 꼭 해야 하는 것)

## 1. 정식 서명 키 만들기 ★ (한 번만)

Play에 올리는 앱은 **잃어버리면 안 되는 고유 키**로 서명해야 합니다. 컴퓨터에서 (Java 설치 필요):

```
keytool -genkeypair -v -keystore release.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

비밀번호를 정하고 이름 등을 입력하면 `release.jks`가 생깁니다.
**이 파일과 비밀번호는 안전한 곳에 백업하세요.** (GitHub 저장소에 올리면 안 됩니다)

## 2. GitHub에 키 등록 ★

저장소 → **Settings → Secrets and variables → Actions → New repository secret** 에서 4개를 추가합니다.

| 이름 | 값 |
|---|---|
| `RELEASE_KEYSTORE_BASE64` | `base64 -w0 release.jks` 결과 (윈도우: `certutil -encode release.jks out.txt` 후 가운데 내용) |
| `RELEASE_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `RELEASE_KEY_ALIAS` | `upload` |
| `RELEASE_KEY_PASSWORD` | 키 비밀번호 |

등록 후 Actions → Android APK → **Run workflow** 를 누르면, Releases에 정식 서명된
`shorts-reels-blocker.aab`(Play 업로드용)와 `.apk`가 올라옵니다. 제목에 `release`라고 표시됩니다.

## 3. Play Console 가입 ★

1. https://play.google.com/console 에서 개발자 계정 생성 (등록비 25달러, 1회)
2. 개인 계정이면 신분 확인을 거칩니다.
3. **2023년 11월 이후 만든 개인 계정은 "비공개 테스트 12명 × 14일"을 먼저 해야** 프로덕션 출시가 열립니다.
   지인 12명 이상에게 테스트 링크를 보내 14일간 설치해 두게 하세요.

## 4. 앱 만들기

Play Console → **앱 만들기**
- 앱 이름: `쇼츠·릴스 차단 - 숏폼 중독 방지`, 기본 언어: 한국어, 앱, 무료

## 5. 스토어 등록정보

`store/listing-ko.md`의 문구를 그대로 붙여 넣으세요.
- 앱 아이콘: `store/icon-512.png`
- 그래픽 이미지: `store/feature-graphic.png`
- 휴대폰 스크린샷 2~8장: 앱을 설치하고 **튜토리얼 첫 화면 / 메인 화면 / 쇼츠 탭이 사라진 유튜브 / 차단 안내 카드** 를 캡처하세요.

## 6. 앱 콘텐츠 (정책 설문) ★

| 항목 | 답변 |
|---|---|
| 개인정보처리방침 | `PRIVACY.md`의 공개 URL (예: GitHub에서 파일을 연 주소) |
| 광고 | 광고 없음 |
| 앱 액세스 권한 | 모든 기능 제한 없이 사용 가능 |
| 콘텐츠 등급 | 설문 진행 → 유틸리티, 폭력/성적 콘텐츠 없음 → 전체이용가 |
| 타겟층 | 13세 이상 (아동 대상 아님) |
| 데이터 보안 | **수집하는 데이터 없음, 공유하는 데이터 없음** (기기 안에서만 처리, 인터넷 권한 없음) |
| 금융 기능·정부 앱·뉴스 등 | 해당 없음 |

### 접근성 API 신고 ★ (가장 중요)

**정책 → 앱 콘텐츠 → 민감한 권한 및 API → 접근성 API** 에서 신고합니다.

- 접근성 도구인가요? → **아니요**
- 기능 설명 (붙여 넣기):

> 이 앱은 사용자의 디지털 웰빙을 위해 YouTube 쇼츠와 Instagram 릴스를 차단합니다.
> AccessibilityService로 YouTube·Instagram 앱의 화면 구성 정보를 읽어 쇼츠/릴스 플레이어가 열리면
> 뒤로 가기 동작을 실행하고, 하단 메뉴바의 쇼츠/릴스 버튼을 오버레이로 숨깁니다.
> 접근 대상은 두 앱으로 한정(packageNames)되며, 사용자는 앱 첫 실행 시 고지 화면에서 동의한 뒤에만 서비스를 켤 수 있습니다.
> 모든 데이터는 기기 내에서만 처리되며 앱에는 인터넷 권한이 없습니다.

- **동영상 링크**가 필요합니다: 휴대폰 화면 녹화로 ① 튜토리얼 고지·동의 화면 ② 접근성 켜기 ③ 유튜브에서 쇼츠 탭이 사라지고, 쇼츠 링크가 바로 닫히는 모습을
  1분 내외로 찍어 YouTube에 **일부 공개**로 올리고 링크를 넣으세요.

## 7. 출시

1. **테스트 → 비공개 테스트** 트랙 생성 → `shorts-reels-blocker.aab` 업로드 → 테스터 이메일 추가
2. 14일 후 **프로덕션** 트랙에 같은 방식으로 업로드 → 검토 제출
3. 검토는 보통 며칠~1주 걸립니다. 접근성 앱은 추가 질문이 올 수 있으니 메일을 확인하세요.

## 심사에서 주의할 점

- 앱 이름·아이콘에 YouTube·Instagram 로고나 이름을 크게 쓰면 상표 문제로 거절될 수 있습니다. (현재 아이콘은 일반 도형이라 괜찮습니다)
- 메뉴바를 다시 그리는 기능은 "다른 앱을 방해한다"고 판단될 여지가 있습니다. 거절되면 해당 기능만 끈 버전으로 다시 제출하면 됩니다.
- 업데이트할 때마다 versionCode가 자동으로 올라가므로 그냥 새 빌드를 올리면 됩니다.
